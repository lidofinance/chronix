# Chronix name

**Chronix** is a local Ethereum development environment with real execution and consensus clients
and validators. The name comes from _chronos_, the Greek word for time. Chronix controls real
protocol time: it pauses the network, produces single blocks and advances through epochs, while
Geth, Lighthouse and the validators do the actual execution, signing and voting.

## Name

Use **Chronix** in titles and prose. Use lowercase `chronix` in package, image and label names, and
the `CHRONIX_` prefix for environment variables.

## Former name

The project was called Panda until 2026-10-16. It was renamed because
[ethpandaops/panda](https://github.com/ethpandaops/panda) and the ethPandaOps panda brand cover the
same Ethereum devnet tooling. The rename is a clean break: environment variables, labels, data
directories, images, client locks and snapshot archives of Panda do not work with Chronix.
