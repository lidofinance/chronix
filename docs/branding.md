# Chronix name

**Chronix** is a local Ethereum development environment with real execution and consensus clients
and validators. The name comes from _chronos_, the Greek word for time. Chronix controls real
protocol time: it pauses the network, produces single blocks and advances through epochs, while the
execution client, Lighthouse and the validators do the actual execution, signing and voting.

## Name

Use **Chronix** in titles and prose. Use lowercase `chronix` in package, image and label names, and
the `CHRONIX_` prefix for environment variables.

## Artwork

The README shows the [animated Chronix mark](assets/chronix-mark-animated.svg): the Ethereum glyph
falls through a pair of portals, and its halves swap into an hourglass. The
[static mark](assets/chronix-mark.svg) is its last frame. Both are vector files built from the
official Ethereum glyph geometry.
